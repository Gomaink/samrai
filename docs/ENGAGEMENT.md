# Favorites, reading history, and notebooks

## Favorites

Each user can favorite books and series. Favorites are private and do not change catalog metadata for other accounts.

The favorites screen groups saved books and saved series. Removing a favorite leaves reading progress and annotations untouched.

## Reading sessions

A reader creates a client session key while a book is open. Activity updates the page and last known position for that book. A session key cannot move from one book to another.

History records the start time, end time when available, first page, last page, and an approximate duration. Clearing history does not reset book progress.

## Combined notebook

The notebook joins PDF and EPUB highlights and notes for the current user. It can be filtered by book, format, kind, or text and exported as Markdown.

Full export paginates through the complete result set. It is not limited to the first 500 annotations. Entries are grouped by book with stable ordering inside each group.

Annotations remain tied to the source book. Deleting a book also removes its annotations.
