# Users and permissions

## Administrator

Administrators can import and delete books, edit metadata, change instance settings, manage users, download backups, inspect logs and audit records, and clear the image cache. They can also read books and keep personal progress and annotations.

## Reader

Readers can browse the library, read books, save progress, manage favorites, review reading history, and create private PDF or EPUB annotations. They cannot import content or change shared metadata.

## Account safeguards

- The last active administrator cannot be disabled or deleted.
- A user cannot delete the account currently in use.
- Disabling an account invalidates access to protected routes.
- Administrative changes are written to the audit log.
- Password resets do not expose the previous password.

Users change their own password from the account menu. Administrators use the user-management screen when a reader cannot sign in.
